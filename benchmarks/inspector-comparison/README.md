# Inspector adapter sources

These Rust adapters are retained for inspection API experiments. The old two-engine timing runner has been retired; the current published PDF comparison uses nine profiles on 200 PDFs.

Use the [PDF comparison protocol](../broad/README.md) for builds, corpus provisioning, scoring and timing. Use the [regression guide](../README.md#regression-checks) for native text, streaming and binding checks. Historical measurement metadata remains in published reports.
